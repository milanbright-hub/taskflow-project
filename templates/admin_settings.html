REGISTRATION ACCESS

Account creation

Control whether new users can create TaskFlow accounts. Existing accounts are not affected.

ROLE POLICY

Allowed account roles

Super Admin

Full platform access, role management, and platform settings.

Admin

User account and platform record management. Cannot grant roles.

User

Private standard workspace; no access to admin endpoints.

Roles can only be granted by an existing Super Admin or through the secure CLI bootstrap.
